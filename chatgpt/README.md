# ChatGPT AIP presentation

**Only for iterative work on user-owned GitHub repositories.** The authoritative per-run instructions are in [`quick.md`](quick.md). Read and apply them each run when accessible.

- **GitHub cards:** show grounded repository changes, commit status, checks and blockers.
- **Next-run cards:** specific action with a 🚀 Execute button, small key (reserved `0` for continuation), one independent `⧉` supplemental textarea, verbatim handoff.
- **Proposal cards:** practical improvement with brief benefit/trade-off; only 👍 authorizes implementation on the next run.

Use compact native cards with subtle 2px outlines. Put action and proposal cards last, without a heading or trailing text. Only the 🚀 Execute button dispatches a next-run action; never trigger without a user gesture.

Standalone renderer, settings, exports and generic adapter behavior are outside the active scope.
