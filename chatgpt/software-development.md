# AIP — iterative GitHub development

Apply [`quick.md`](quick.md) to **every response** during iterative ChatGPT work on the user's own GitHub repositories. Refresh it at each run start when accessible; if unavailable, say so.

1. Report only verified GitHub changes, commits, checks and blockers in compact cards.
2. Offer meaningful next-run action cards; key `0` continues agreed work. Preserve action, parameters, context and verbatim supplemental text.
3. Propose worthwhile improvements ranked by practical impact; a single 👍 requests implementation in the next run.

Next-run prompts must repeat the instruction to read, apply and propagate the quick profile. The active UI ends with action/proposal cards, no heading or text afterward. No general-purpose protocol infrastructure or additional UI components.

See `quick.md` for the precise card and handoff contract.
